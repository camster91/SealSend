- [x] Review live crawlability, canonicals, robots and sitemap.
- [x] Draft focused strategy, competitor observations and content calendar.
- [x] Build and validate two new feature pages with metadata, sitemap links and responsive/accessibility checks.
- [ ] Publish the reviewed candidate through protected CI and verify the live revision. Local validation is not publication.

- [ ] Verify real email/OTP inbox delivery with an approved test recipient.
- [ ] Cameron: identify10 willing hosts; review outreach draft before sending. No outreach is sent by this plan.
- [ ] Codex: implement/verify privacy-conscious channel attribution; reconcile existing activation events to actual cohorts.

## Phase2 — Learn and expand, weeks5–12
Onboard hosts, fix recurring friction, publish4 practical guides and approved host stories, improve existing audience pages. Verify actual phone check-in with real devices. Review activation and support weekly. Publish comparison content only after research/user evidence supports it. Measure repeat intent without advertising unlimited beta events.

## Phase3 — Scale, weeks13–24
Select the channel producing activated hosts. Develop adjacent audiences only when the first one retains users. Trial partnerships and selective relevant directories; every external submission/contact needs authorization. Propose paid acquisition only with approved cap, attribution and stop condition. Broader provider/payment release remains separate from marketing acceptance.

## Phase4 — Authority, months7–12
Build original host studies and reusable resources; refresh successful pages and evaluate retention, monetization and support costs. Publish stronger claims only with evidence. Continue only channels that acquire hosts who use the product.

## Weekly operating rhythm
Monday: funnel and search scorecard. Midweek:2 host sessions and one content asset. Friday: friction fixes and experiment review. Owner Cameron for audience, access, contacts and spending; Codex for bounded implementation, research and QA. Next operational dependency: connected Search Console plus first consenting hosts.
